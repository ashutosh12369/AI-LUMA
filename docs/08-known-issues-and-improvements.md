# Known issues and improvements

Every item below was checked against the code at commit `4ac41a3` (latest on `main` when these docs were written). Line numbers point to that version. Where something could not be proved from the code alone, it is marked **(likely)**, with the reason.

**Severity:** 🔴 security or money · 🟠 functional bug · 🟡 code quality / scaling.

**How some were checked:**
- A `no-undef` lint pass over the whole backend. It found exactly 6 undefined names: 4 in `github.agent.js`, 1 in `planner.node.js`, 1 in `pdfRag.agent.js`.
- A real `vite build` of the frontend. It **fails** (see [F1](#f1)).
- Reading the source of `express-http-proxy@2.1.2`. Its default path resolver forwards `req.url`, which is how [F5](#f5) was confirmed.

---

## Root cause of several bugs: the auto-commenting script

[comment_script.js](../backend/services/agent/comment_script.js) sent **every** `.js` / `.jsx` file to an LLM with the instruction "add Hinglish comments, don't change code", then **overwrote the file** with whatever came back. That ran in commit `2420ae2`. The model did change code:

- It dropped import lines.
- It removed the suggestion-card data.
- It changed an import path.

Commit `a3599d3` ("Restore missing imports in agent files") fixed some files but missed others. The survivors are [F1](#f1), [F2](#f2), [F3](#f3) and [F22](#f22).

> **Interview lesson:** never let a tool rewrite source files without a diff review, a build and a lint step. A simple CI job (`eslint` + `vite build`) would have caught all four.
